# OpenCode

Diese Struktur definiert die lokalen OpenCode-Agenten für das Projekt.

## Rollen

- Builder → Claude Sonnet 4.6
- Reviewer → GPT-5.4 mini
- Test Writer → GPT-5.4 mini
- Auditor → GPT-5.4 mini
- Eskalation / schwieriges Problem → GPT-5.4

## Zweck

Die Agenten unterstützen Implementierung, Reviews, Tests und Qualitätskontrolle für die Astro-Webseite.
